Scope: DESIGN v1, CURATION_PROTOCOL, LESSONS, 95 family dirs (sampled), panels, DATA.md, .gitignore, run/subset manifests.
verify_provenance run on K01_RPROT_L23 (PASS, 0 warn), Y03_URA1_HGT (PASS, 4 warn), E03_Rab (PASS, S-polytomy warnings). `scripts/audit_sources.py` DOES NOT EXIST although DESIGN s5/s10 promise it.

## MUST
1. **Missing audit_sources.py.** The denylist is only enforced by humans. Write it: scan every family.yaml `sources`, build.py strings, assertions `source_id`, and cited files against a denylist regex (OMA, OrthoFinder, Compara, HCOP, VGNC, OHNOLOGS, PANTHER, TreeFam, eggNOG, OrthoDB, PLAZA, LOC_) plus an allowlist of `source_method`; fail the freeze on any unexplained hit. Manual grep found no denylisted truth source: hits are Ensembl used only for ID/locus mapping (V02, V04), Compara noted as excluded (V03). K04/E03 are acceptable (see 6).
2. **Tool outputs committed to git in runs/** (~21 MB tracked: orthofinder `of_core.tar.gz`, `of_orthologues.tar.gz`, FastOMA orthoxml, hogs.tsv.gz) while .gitignore only excludes `runs/**/raw/`. Curation is separated by protocol only. Fix: add `runs/**/*.tar.gz`, outputs to .gitignore or move them to the release archive (DESIGN s8 says archive, not git); `git rm --cached`. Add a CI-style check that no `families/*/build.py|curation_log.md` matches `runs/|results/` (currently clean: grep found nothing).
3. **Freeze artefacts do not exist.** No `families/MANIFEST.sha256`, no `ERRATA.md`, no freeze tag, yet E subset runs (started 00:30) and Y/K evaluation (commit e0f02f4, 00:39) already exist. Results were therefore produced before the references were frozen (Y/K scored while refs still editable; E09 abandoned at 00:29 and logs edited 00:30 after K/Y results existed). Must freeze Y/K/E/P references (hash + tag) BEFORE any further scoring, and record that Y/K evaluation preceded freeze; any post-evaluation edit to Y/K families must go through ERRATA with before/after numbers.
4. **DATA.md omits data actually used.** `literature/raw/P_shared/all.locus_brief_info.7.0` (7 MB, rice MSU locus table, used by P01/P02 via `plib.MSU_INFO` and sha256-recorded in P02 family.yaml) has no DATA.md row; it is also neither git-tracked nor ignored (risk of an accidental add). Add row (source, URL, version 7.0, sha256, licence, redistribution n) and a .gitignore line. Also check that every `files:` path in all family.yaml has a DATA.md row (script it in make_data_md.py; DATA.md has only 1 COG2020 row and 22 paper rows vs 57 paper folders).
5. **Run manifests incomplete.** The two E/subset manifests have `status: running`, `finished: null`, and `outputs` with no sha256 (done runs have 1-7). Scoring must refuse manifests that are not `done` or lack output checksums. Manifests record absolute /scratch paths and `git_commit` of a tree that was dirty by definition; add a `dirty` flag and relative paths.
6. **Y03 quote support.** Y03_A2/A3/A4 are tagged T1 for the HGT event, but verify_provenance warns that the quotes contain none of the supported labels. A4 (Gojkovic 2004 abstract: "closely related to a bacterial DHODase from L. lactis") is phylogenetic similarity, not a statement of transfer at a level, so it is not T1 for the event. Demote A4 to supporting evidence (no tier) and make the "quote lacks target label" warning an error for T1 events and D-levels in the blind verifier sample.
