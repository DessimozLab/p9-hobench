# Round 1 review — synthesis

Reviews (written independently, no reviewer saw another's review):
01 External PI (PI) · 02 Prior work (PW) · 03 Statistician (ST) · 04 Data scientist (DS) · 05 Algorithms & compute (AC) ·
06 AI-agent failure modes (AI) · 07 Molecular evolution (ME). Files: `reviews/round1/0*_*.md`.

All seven reviewers found the core idea sound: merge levels, assertion tiers, event recovery, blind curation and no
composite score. Nobody asked to change the goal. Several reviewers found the same errors on their own, which makes those
findings very likely correct:
- **β-lactamase "non-homologous classes" is factually wrong.** Found by 4 of 7 reviewers (PI, PW, AI, ME).
- **The ∞/family-root handling is wrong.** It shows up in 3 forms: AC-1, ST-2 and ME-1.
- **Genome-scale collections must not be pooled with single families.** Raised by 5 reviewers (PI, PW, ST, ME, AC).
- **Correct deep merges of homologous reference families count as "contamination".** Raised by PI, ME and ST.

Some reviewers tested the code directly:
- ST ran trivial predictors: all-singletons scores 0.92 merge accuracy and 1.0 event recovery on a kinesin-like toy.
- AC tested the formalism on toy cases: a correct TGD prediction scores 0.33.
- AC also inspected the calibration output and found that FastOMA silently renamed the `KE` level.
- AI found a committed HTTP-500 error body (`literature/raw/C/PMC6291210.xml`).

Priority column: the highest priority any proposer gave. Rec. = PI-coordinator recommendation (accept / modify / reject).

## Cross-reviewer disagreements and how they were resolved
1. **∞ handling**: ST-2 would collapse predictions above the family level to ∞; AC-1 and ME-1 propose interval references. **Intervals** win: they fix both symptoms and keep information (A1).
2. **Size control in subset mode** (D5): DS-5 proposes 2-hop (larger, tests over-merging); AC-7 proposes ≥50% qcov (smaller). Resolved as 1-hop + capped domain-only decoys, with 2-hop as a sensitivity run.
